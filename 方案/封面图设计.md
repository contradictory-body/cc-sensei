# cc-sensei 封面图设计规格

> 用途：GitHub Social Preview（1280x640px）
> 风格：蒸馏器/科技风
> 核心叙事：混乱的海量源码 → 蒸馏器 → 整齐的知识结晶

---

## 1. 画面结构

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  ┌─────────┐       ┌──────────┐        ┌─────────────────────┐   │
│  │         │       │          │        │ ▪ ▪ ▪ ▪ ▪ ▪ ▪ ▪    │   │
│  │ 密集的  │  ──>  │  发光的  │  ──>   │ ▪ ▪ ▪ ▪ ▪ ▪ ▪ ▪    │   │
│  │ 代码流  │       │  蒸馏器  │        │ ▪ ▪ ▪ ▪ ▪ ▪ ▪ ▪    │   │
│  │         │       │          │        │ ▪ ▪ ▪ ▪ ▪ ▪ ▪ ▪    │   │
│  └─────────┘       └──────────┘        └─────────────────────┘   │
│                                                                    │
│                    🎓 cc-sensei                                    │
│                                                                    │
│      310K lines of source → 32 queryable modules via MCP          │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### 左区 — 源码洪流（占 30% 宽度）
- 密集半透明的等宽字体代码行，快速流动感
- 代码内容：真实 TypeScript 片段（import 语句、function 声明）
- 颜色：暗灰 (#8b949e) 到暗绿 (#3fb950)，20-40% 不透明度
- 行与行之间有轻微模糊 / motion blur，暗示"太多读不完"

### 中区 — 蒸馏器（占 25% 宽度）
- 形状：上宽下窄的漏斗 / 三角烧瓶轮廓
- 风格：线条描边 + 内部紫色渐变发光
- 顶部入口：代码流注入，粒子效果
- 底部出口：结晶光束射出
- 发光核心：中心一个亮点，像"提炼中"
- 颜色：紫色渐变 (#a855f7 外圈 → #6366f1 核心) + 白色光晕

### 右区 — 知识结晶（占 30% 宽度）
- 32 个小方块/六边形，整齐排列成 4×8 或 8×4 网格
- 每个方块微微发光，蓝紫色 (#818cf8 → #a78bfa)
- 前几个方块上可以隐约显示模块编号（M01, M02...）
- 方块之间有细连线，暗示"关联知识网络"
- 整体传达：从混乱到秩序、从海量到精炼

### 底区 — 品牌信息
- 项目名：`cc-sensei` 大字，白色，半粗体
- 带 🎓 emoji 或毕业帽图标（呼应 sensei 主题）
- 副标题：`310K lines of source → 32 queryable modules via MCP`
- 字体颜色：白色 + 50% 透明度的灰色副标题

### 背景
- 纯深色：#0d1117（GitHub 深色模式标准背景色）
- 可选：极淡的网格线 / 电路板纹理（5% 不透明度）

## 2. 配色方案

| 元素 | 颜色 | 用途 |
|---|---|---|
| 背景 | #0d1117 | GitHub 深色背景，视觉统一 |

| 副标题 | #8b949e | 灰色 |

## 3. AI 生图 Prompt

### Midjourney v6 Prompt

```
A dark tech-themed banner image (1280x640px), showing a visual pipeline from left to right:

On the left: dense streams of semi-transparent code text in monospace font (TypeScript/JavaScript), flowing rapidly with slight motion blur, colored in muted gray-green tones, representing 310,000 lines of source code that feel overwhelming.

In the center: a glowing glass distillation funnel/flask shape, with code particles flowing in from the top and crystallized light beams emerging from the bottom. The funnel has a purple gradient glow (violet to indigo) with a bright white core point, suggesting active refinement.

On the right: a neat grid of 32 small glowing cubes/hexagons arranged in 4 rows of 8, each emitting soft blue-purple light, connected by thin luminous lines suggesting a knowledge network. Some cubes have faint labels (M01, M02...).

Bottom center: the text "cc-sensei" in clean white bold sans-serif, with a graduation cap icon. Below it in smaller gray text: "310K lines → 32 modules via MCP"

Background: solid dark (#0d1117), very subtle grid pattern at 5% opacity.

Style: clean, minimal, tech/developer aesthetic, no photorealism, vector-inspired with subtle glow effects. --ar 2:1 --v 6
```

## 4. 备选方案

如果蒸馏器方案效果不理想，可尝试：

### B 方案：极简文字版（纯设计，不靠 AI 生图）

用 Figma / Canva 手动做：
- 深色背景
- 左边大字 `cc-sensei` + 🎓
- 右边一行数字：`310K → 32 modules`
- 底部小字：`Your AI's Claude Code architecture sensei`
- 配几个 shields.io badge 图标

### C 方案：终端截图风格

- 模拟一个深色终端窗口
- 里面显示 `$ npx cc-sensei` 的输出（用 demo-screenshot.ts 的部分输出）
- 底部配文字 slogan

---

## 5. 使用方式

1. 用上方 AI prompt 在 Midjourney/DALL-E/SD 中生成
2. 可能需要 2-3 次迭代调整（文字通常需要后期 PS 叠加）
3. 确保最终图片符合 1280×640px（GitHub 会裁切正方形缩略图，确保核心内容在中间 640×640 区域）
4. 上传到 GitHub 仓库设置 → Social Preview
